# 许可证与来源

此仓库的原始改动及基于 GPL 作品的衍生代码采用 GPL-3.0-or-later。完整许可证见 [LICENSE](../LICENSE)。保留 [MAKO](../licenses/MAKO.md)、[GSF-Kedavra](../licenses/GSF-Kedavra.md) 和 [ANVIL](../licenses/ANVIL.txt) 的上游通知。

MAKO Renderer 从固定提交应用本项目的单独补丁。运动估计与 warp shader 在本地从固定 GSF-Kedavra 源码生成。NPU socket 客户端及 daemon 从固定的 Vela fork 取得，它们保留上游许可及补充授权。ANVIL 源码和 Vulkan-Headers 的固定提交也列在 [sources.json](../sources.json)。

Qualcomm QAIRT SDK、模型权重、游戏文件和实机原始数据由操作者按各自条款在本地准备。仓库没有包含这些文件。
